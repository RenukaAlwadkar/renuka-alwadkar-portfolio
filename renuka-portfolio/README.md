# Renuka Alwadkar - Personal Portfolio

Welcome to the repository for my personal portfolio! This project showcases my journey as a Computer Engineering student, freelance UI Designer, and full-stack developer. 

## Tech Stack
This portfolio is built using **React** and **Vite** for a fast, optimized, and modern web experience.

## What's Inside
* **Projects:** A showcase of my technical projects, including my work as a Smart India Hackathon (SIH) 2025 Winner and SIH 2024 Finalist.
* **Experience & Skills:** Details on my freelance UI design experience, full-stack development, and DevOps learning journey.
* **Certifications:** Highlights of my technical credentials, including my Microsoft, LinkedIn, and NPTEL Java programming certifications.
* **Resume:** Easy access to my most up-to-date professional resume.

## Local Development

To run this project locally on your machine:

1. Clone the repository.
2. Navigate to the project directory: 
   `cd renuka-portfolio`
3. Install the dependencies: 
   `npm install`
4. Start the development server: 
   `npm run dev`
